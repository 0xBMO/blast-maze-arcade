# Blast Maze: Arena Bomber

Videojuego arcade de laberintos desarrollado exclusivamente con tecnologías web nativas (HTML5 Canvas, CSS3, JavaScript ES6) y backend en Node.js, sin frameworks ni motores de desarrollo externos.

## Integrante
* Ricardo Juárez Garduño

## Requisitos de Ejecución
* Node.js v18 o superior instalado en el sistema.
* Navegador web moderno con soporte para Canvas y ES6 Modules.
